MicText for Windows (x64)
========================

1. Extract the entire ZIP to a folder you want to keep.
2. Double-click MicText.exe. Keep bin, models and icons beside it.
3. On first launch, choose your microphone in Settings. Use Test mic to
   check the level, then Save.
4. Click into a text field, hold Right Ctrl, speak, and release to type.

Microphone, hotkey and model settings are available from the MicText tray
icon's Settings menu. Exit closes MicText. Double-click MicText.exe to
start it again. You can create a shortcut to it wherever you prefer.

No AutoHotkey install, administrator access or internet connection is
needed to run this package. Audio and transcription stay on your PC.
Allow microphone access in Windows privacy settings if it is disabled.

Settings and learned words live in %USERPROFILE%\.mictext, shared with an
existing MicText installation. Extra models can also go in that folder's
models subfolder. The bundled English base model is ready to use offline.
Exit an older MicText instance before launching this version.

Windows 10/11 x64. This build is unsigned.
Source and dependency notices are included in source and licenses.
